# Data Structures & Algorithms

Python implementations of core DSA building blocks, written to practise problem-solving fundamentals.

| Topic | Contents |
|:--|:--|
| **Sorting** | Bubble, selection, insertion and merge sort (`Sorting/`) |
| **Arrays** | Missing number, move zeroes to end, find the single element, rotate, union (`Array/`) |
| **Recursion** | Recursive problem patterns (`Recursion.py`) |
| **Maths** | Number-theory and math utilities (`Maths.py`) |
| **Patterns** | Pattern-printing exercises (`Pattern.py`) |

## Run

```bash
python3 Sorting/merge.py
```
